# Contributing to EMF-Visu

Thank you for helping improve and test EMF-Visu, especially as a noncommercial educational,
research, or public-interest project.

## What feedback is useful

At this stage, the most useful contributions are reproducible bug reports and carefully
explained suggestions:

- Incorrect field directions, magnitudes, units, or physical-law results.
- Differences between analytical expectations and displayed values.
- Rendering problems in 2D or 3D.
- Unexpected behavior when changing a model, preset, parameter, or time.
- Installation, startup, and platform-specific problems.
- Improvements that make the software more useful for teaching, learning, and public research.

## Before opening an issue

1. Check whether a similar issue already exists.
2. Identify the exact model and preset, if applicable.
3. Include the steps needed to reproduce the problem.
4. State what you expected and what actually happened.
5. Attach a screenshot or a short screen recording when it helps.
6. Include relevant application logs, after removing credentials, tokens, private URLs,
   personal data, and other sensitive information.

For physics issues, please include units, parameter values, coordinate location, and simulation
time. Distinguish a suspected physical error from a visualization or camera issue when possible.

## Code contributions

Noncommercial contributions that improve EMF-Visu as educational, research, or public-interest
software are welcome.

Before substantial changes, please open an issue to discuss the proposed approach. Pull requests
should:

- Explain the problem and the proposed change.
- Include focused tests for changed behavior.
- Preserve physical assumptions, units, and documented limitations.
- Be submitted only by contributors who have the right to contribute the code.

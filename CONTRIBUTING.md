# Feedback and bug reports for EMF-Visu

Thank you for helping test EMF-Visu. The project welcomes reproducible bug reports,
physics-validation feedback, visualization feedback, and feature suggestions.

## This is an issue-only feedback process

The EMF-Visu repository is maintained exclusively by its owner.

- Please use GitHub Issues to report bugs, incorrect physical results, confusing
  visualizations, installation problems, or suggest improvements.
- **Code contributions and pull requests are not accepted.**
- Do not expect external code, patches, branches, or pull requests to be merged.
- No outside contributor is granted write access to the original repository.
- The project owner independently decides whether and how to implement reported issues.

Users may create their own copies or forks only within the permissions of the
PolyForm Noncommercial License 1.0.0. A fork is a separate repository; it does not
provide write access to this original repository or imply that its code will be adopted.

## What feedback is useful

- Incorrect field directions, magnitudes, units, or physical-law results.
- Differences between analytical expectations and displayed values.
- Rendering problems in 2D or 3D.
- Unexpected behavior when changing a model, preset, parameter, or simulation time.
- Installation, startup, and platform-specific problems.
- Suggestions that could make the software more useful for education, learning, and research.

## Before opening an issue

1. Check whether a similar issue already exists.
2. Identify the exact model and preset, if applicable.
3. Include the steps needed to reproduce the problem.
4. State what you expected and what actually happened.
5. Attach a screenshot or a short screen recording when it helps.
6. Include relevant application logs only after removing credentials, tokens, private URLs,
   personal data, and other sensitive information.

For physics issues, include units, parameter values, coordinate location, and simulation time.
When possible, distinguish a suspected physics error from a visualization or camera issue.

## Project scope

EMF-Visu is an evolving analytical electromagnetic visualization project. It is not currently
a general-purpose FEM/FDTD solver. Please check the README and architecture documentation
before reporting an unsupported capability as a defect.
